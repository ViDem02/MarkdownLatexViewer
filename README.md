# Markdown + LaTeX Viewer

A split-pane markdown editor with live preview and KaTeX rendering.

**Live Demo:** https://md-math-viewer.web.app/

## Features

- Live markdown preview
- LaTeX math rendering ($...$, $$...$$, \(...\), \[...\])
- Manual KaTeX rendering (select text → right-click)
- Auto-save to browser storage
- Import/Export markdown files
- Resizable panes
